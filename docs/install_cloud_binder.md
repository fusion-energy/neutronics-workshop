# Install in the Cloud (binder)

We have a Docker image on Binder which can be loaded up in your browser by clicking the Binder image below.

[![](https://mybinder.org/badge_logo.svg){fig-alt="Binder"}](https://mybinder.org/v2/gh/fusion-energy/neutronics-workshop/HEAD)

This allows running and editing of the task files from your browser. Right click a task in the `tasks` folder and choose **Open With** and then **Notebook** to run it cell by cell, see [Running the tasks](running_the_tasks.md) for more.
